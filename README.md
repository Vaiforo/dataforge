# Cart Scope

Cart Scope — проект аналитики электронной торговли: исследование поведения
посетителей, клиентского опыта и проблем в работе интернет-магазина.

Сейчас подготовлена основа проекта: изолированное Python-окружение,
генератор демонстрационных сессий и версионирование CSV через DVC.
Аналитические модели и интерфейс пока не реализованы.

## Окружение

Проверено на Python 3.12. Команды выполняются из корня репозитория.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

В PowerShell окружение активируется командой `.venv\Scripts\Activate.ps1`.
Версии DVC и его транзитивных зависимостей зафиксированы в `requirements.txt`
командой `python -m pip freeze` из чистого окружения. Генератор использует
только стандартную библиотеку Python.

## Структура

```text
data/
  raw/             # исходные данные; не редактируются вручную
  processed/       # результаты обработки
  external/        # данные из внешних источников
notebooks/         # исследовательские ноутбуки
src/
  data/            # получение и генерация данных
  features/        # подготовка признаков
  models/          # обучение и применение моделей
  visualization/   # построение графиков
models/            # сохранённые модели
reports/           # отчёты и графики
requirements.txt
```

Пустые каталоги обозначают места для будущих модулей. Данные, модели,
окружение и локальный кэш DVC исключены из Git. В Git хранятся код,
документация и файлы метаданных `.dvc`. Перед добавлением ноутбуков нужно
очищать их выводы.

## Демонстрационные сессии

`data/raw/demo_sessions.csv` содержит 100 искусственных сессий с seed `42`.
Это проверка генерации, хранения и восстановления данных, а не реальная
статистика магазина или выбранный основной датасет.

| Поле | Значение |
| --- | --- |
| `session_id` | Синтетический идентификатор `demo_0001`, … |
| `duration_seconds` | Случайная целая длительность от 10 до 1800 секунд |
| `products_viewed` | Случайное целое число просмотренных товаров от 1 до 20 |
| `purchased` | Искусственный флаг покупки: 0 или 1, вероятность 1 равна 0,2 |

Показатели генерируются независимо. Они не моделируют поведение покупателей;
доля покупок в конкретном файле может отличаться от 20%.

Если CSV ещё отсутствует, его можно создать без доступа к хранилищу:

```bash
python -m src.data.generate_demo
```

Одинаковые параметры дают одинаковый CSV. Существующий файл не перезаписывается.
Для отдельного примера:

```bash
python -m src.data.generate_demo --rows 50 --seed 7 --output data/raw/demo_preview.csv
```

## Хранение данных через DVC

DVC уже инициализирован. Для локальной проверки используется каталог
`../cart-scope-dvc-storage` вне репозитория. Это отдельная копия данных на
текущем компьютере; она не обеспечивает доступ с другого компьютера.
Путь задаётся локально в игнорируемом `.dvc/config.local` и не переносится
вместе с репозиторием.

Настройка на новом компьютере и сохранение сгенерированного CSV:

```bash
dvc remote add --local -d local ../cart-scope-dvc-storage
dvc add data/raw/demo_sessions.csv
dvc push
dvc status
```

Для восстановления из уже заполненного хранилища после настройки remote:

```bash
dvc pull
```

Если доступа к хранилищу нет, сначала запустите генератор с параметрами
по умолчанию, затем `dvc status`: результат должен быть `Data and pipelines
are up to date.`. Для общей работы потребуется доступное участникам
хранилище DVC. Его адрес и способ подключения выбираются отдельно.

`dvc push` переносит данные в настроенное хранилище. Код и метаданные
публикуются отдельно средствами Git.
